# 网站计算候选设计

## 1 工作目录与执行入口

使用内容完整的 rfic_codex_project_web 工作副本。

- 运行 rfic_certify.py 完成认证。
- 运行 rfic_web_run.py 提交计算任务。
- 编辑 json/param.json 设置任务和参数。
- PA 与匹配任务分别参照 param.pa.example.json 和 param.matchingcircuit.example.json。值的类型必须与相应模板完全一致。

只通过已有脚本执行在线任务。允许编辑参数 JSON，程序脚本仅允许创建或修改 run.py。

## 2 登录与余额处理

提交前查看 json/token.json。

1. 没有 token.json 时运行 rfic_certify.py，在用户桌面显示命令行，让用户输入账号密码。认证结束后关闭该界面。
2. token.json 存在仍可能过期。若 rfic_web_run.py 提示 token 过期并进入登录流程，终止主程序，不将该登录界面推送给用户，改为运行 rfic_certify.py 完成认证。
3. token 文件保存在本地，仅由认证客户端用于目标服务的鉴权请求；不得打印给第三方、写入公开报告或提交 GitHub，不上传到其他服务。
4. 主程序提示余额不足，表示账户积分小于 100，函数会终止。提醒用户充值，余额充足后继续提交。
5. 同时只提交一个任务，当前任务未返回前不提交新的任务。

账号或密码错误时，认证脚本会在同一窗口要求重新输入两项；输入 q 可取消，不自动重新打开窗口或提交设计。以有效 token 已保存、用户信息验证成功为认证完成依据，不能只凭进程结束或“登录成功”字样判断。若窗口随后提示登录失效并删除 token，本轮认证未完成，应重新运行认证脚本；网络错误也不能直接判为账号密码错误。

本节只约束 Windows 网站客户端：只有认证时的命令行显示给用户，其余网站执行过程不显示。Cadence 是否显示界面由该电路设计开始时确认的 show_gui 决定，不能将这里的规则套用于 Cadence。

## 3 从需求生成参数

将自然语言要求转成具体参数。

- 工艺节点、增益指标、OP1dB 指标必须由用户提供。
- 其余参数未明确提供时，可自行调整以满足需求。
- 用户已经明确的要求不能自行更改，必须满足。
- 工作频率取用户要求的中心频率。例如 23–25 GHz、中心 24 GHz 时提交 24 GHz。
- 用户没有明确频率要求时可自行选择，但选定后保持不变。
- 要求超出合法参数范围时提醒用户更改要求。

## 4 PA 任务参数

在 param.json 中选择 PA 任务，提供下列字段。

| 字段 | 含义 | 合法取值 |
| --- | --- | --- |
| Tech | 工艺节点 | "65nm"、"40nm"、"28nm" |
| Vdda | 工作电压，V | 65nm 为 1.1、1.2、1.3；40nm 为 1.0、1.1、1.2；28nm 为 0.9、1.0、1.1 |
| Frequency | 工作频率，GHz | 1–80 |
| Gain_low | 增益低限 | 0–30 |
| Gain_up | 增益高限 | 0–30 |
| OP1dB_low | 1 dB 压缩点输出功率要求 | 0–25 |
| DE_P1dB_w | 压缩点漏极效率权重 | 1–100 |
| Iq_w | 静态电流权重 | 1–100 |
| NFmin_w | 最小噪声系数权重 | 1–100 |
| V_over | 超压选项 | 1.3、1.5、1.7、1.9 |

增益上下限要包含用户给出的增益指标。在线查询的 OP1dB 参数按原规则选在用户 OP1dB 指标以下，最终采纳时仍按用户的原始 OP1dB 指标判断是否达标。

根据用户需求选择三项权重。

- DE_P1dB_w 越高，网站越优先提高 DE_P1dB。
- Iq_w 越高，网站越优先降低 Iq。
- NFmin_w 越高，网站越优先降低 NFmin。
- V_over 未明确要求时由 Codex 选择。

## 5 匹配网络任务参数

| 字段 | 含义 | 合法取值 |
| --- | --- | --- |
| freq_value | 中心频率，GHz | 0.5–80 |
| freq_scope | 中心频率两侧的百分比半带宽 | 0–15 |
| Z_L_real | 负载阻抗实部 | 0–1000 |
| Z_L_imag | 负载阻抗虚部 | -1000–1000 |
| Z_opt_real | 目标阻抗实部 | 0–1000 |
| Z_opt_imag | 目标阻抗虚部 | -1000–1000 |
| S11 | 最差可接受匹配度 S11_max | -100–0 |
| IL | 最大可接受插入损耗 IL_max | 0–100 |
| tech | 工艺节点 | "65nm"、"40nm"、"28nm" |
| layer_p_thickness | 主线圈金属层厚度 | 见下表 |
| layer_s_thickness | 副线圈金属层厚度 | 见下表 |
| input_type | 信号传输方式 | "DIFF_DIFF"、"SINGLE_DIFF"、"DIFF_SINGLE"、"SINGLE_SINGLE" |

### 5.1 频率范围

匹配网络的中心频率、工艺节点与 PA 一致，范围至少覆盖用户工作频带。

上述中心频率规则为默认要求。仅当用户明确允许宽带输入、输出网络使用不同设计中心作错峰匹配时，才按授权分别填写；PA 工艺及用户工作频带不变，两网络各自的设计范围仍至少覆盖目标频带，并在各自设计频率复核阻抗。用户规定必须填写同一中心时不得自行偏离。错峰不用于给单频任务额外添加宽带要求，具体策略见 optimization.md 第 8 节。

- 下限为 freq_value × (1 − freq_scope/100)。
- 上限为 freq_value × (1 + freq_scope/100)。
- 用户要求 9–11 GHz、中心 10 GHz 时，freq_value 填 10，freq_scope 填 10。

### 5.2 阻抗与信号方式

| 网络 | 负载阻抗 | 目标阻抗 | 默认信号方式 |
| --- | --- | --- | --- |
| 输入匹配 | PA 实际输入阻抗 Zin | 50 ohm | SINGLE_DIFF |
| 输出匹配 | 50 ohm | PA 的负载阻抗 ZL | DIFF_SINGLE |

网站 PA 返回的是 Zin,conj，需要取共轭得到实际 Zin 后再填写输入匹配负载。

S11 是可接受的最差匹配度，IL 是可接受的最大插损。用户未明确要求时，推荐 S11=-10、IL=1。用户有具体要求时按用户要求填写。

### 5.3 主副线圈厚度组合

| 工艺 | 主线圈厚度 | 对应可选副线圈厚度 |
| --- | --- | --- |
| 65nm | 3.4 | 3.4、2.8、1.45、0.9 |
| 40nm | 3.5 | 3.5、3、0.85 |
| 40nm | 3.4 | 3.4、2.9、0.9 |
| 28nm | 3.5 | 3.5、3、0.85 |

选择当前工艺节点下最厚的主、副线圈金属层。用户给出具体要求时按其要求填写。

## 6 PA 结果的评估与采纳

1. 提交后，程序先通过 print 输出增益、OP1dB、DE_P1dB 等计算指标，此时还没有用于 Wizard 的生成代码。
2. 由 Codex 阅读指标并决定是否采纳，不让用户作候选选择。
3. 拒绝时函数直接结束。自行调整 param.json，重新提交，不在每轮请求用户确认。
4. 采纳时网站返回形如 A/.../.../... 的生成代码，将指标与代码写入 pa_opt.json。
5. 采纳后读取该文件，供后续原理图导入和匹配网络设计使用。

## 7 匹配结果的评估与采纳

1. 程序先后输出补偿电容 Cp、Cs，并将 Smith 圆图、插损图下载到 png。此时尚未下载最终归档。
2. 查看两张图，判断匹配度、插入损耗等是否满足要求。由 Codex 决定，不交给用户。
3. 拒绝时函数直接结束。调整 param.json 再提交，不在每轮请求用户确认。
4. 采纳后归档下载到 gds，其中 txt 文件包含匹配网络生成代码。
5. Cp/Cs 不会由程序自动写入本地。立即将数值、单位及其所属输入或输出网络保存到本次设计记录，供后续仿真调用。

## 8 反复计算仍未达标

网站结果应满足所有设计条件，自行调整参数并重复计算。经过至少 10 次调整仍未满足时，可以采纳最接近设计条件的一组。

该规则分别适用于 PA 和匹配任务。保留这组结果供后续流程使用，并明确仍需本地优化的未达标项。
