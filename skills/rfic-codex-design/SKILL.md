# RFIC Codex Design

术语约定：PA 有源核心指不含输入、输出匹配网络的有源电路；完整 PA 电路指接入输入、输出匹配网络后的整体电路。描述仿真、性能和验收时，应明确所指对象。

理解用户的电路指标，调用已有程序完成网站候选计算、Virtuoso 导入、EMX 提取、完整 PA 电路仿真及优化。具体步骤按下表读取对应参考文件。

## 总体工作流程

1. 根据用户需求解析电路应达到的指标。初次运行时先完成环境配置。
2. 调用 RFIC-GPT 计算初始有源电路参数。结果未达标时微调提交参数并迭代。
3. 根据采纳方案返回的输入、输出阻抗，分别设计输入和输出匹配网络。
4. 在 Virtuoso 中通过 RFIC-GPT_Wizard 导入原理图和匹配网络版图。
5. 对匹配网络进行 EMX 仿真，再构建完整原理图并进行完整 PA 电路仿真，取得基线数据。
6. 分析未达标指标，判断应调整匹配网络、晶体管尺寸还是偏置。
7. 调整匹配网络时，先扫描补偿电容，仍未达标再重新设计匹配版图。
8. 调整尺寸时，先调整放大管以满足稳定性以外的指标，随后调整中和管以满足稳定性条件。
9. 每次调整迭代收敛后重新进行完整 PA 电路仿真，对照全部指标验收。

## 执行规则

- 由 Codex 阅读网站返回的指标、Smith 图和插损图，决定是否采纳，并回答程序的采纳提示。按照网站计算参考文件自行迭代，不把候选采纳决定交给用户，也不在每轮计算前请求确认。
- 同时只向网站提交一个任务，原任务未返回前不提交新的任务。余额不足时提醒用户充值，余额充足后继续。
- 网站登录只通过 rfic_certify.py 完成。需要账号密码时显示可见命令行，确认取得有效 token 并完成认证后关闭。其余网站客户端程序不显示到用户界面；这不限制 show_gui=true 时显示 Cadence 窗口。主程序提示 token 过期时，终止主程序，改用认证脚本登录。
- 用户发起电路设计任务时必须说明是否可视化；未说明时，开始设计前先确认。按用户选择在 deploy.json 设置 show_gui：false 使用脚本管理的 Xvfb 虚拟显示，true 使用实际桌面的图形显示。同一电路从生成、仿真到全部优化结束不得改变该参数，也不能中途关闭重开来切换模式。新设计开始前才可重新选择。
- 使用 RFIC.py 的常驻 Virtuoso 会话，不为每次函数调用外套 xvfb-run 或另开 Virtuoso。任务完成后统一调用 close_virtuoso()，关闭本工程会话及其创建的虚拟显示；具体接口见 use_of_func.md 第 9 节。
- **程序脚本只允许创建或修改 run.py。** 通过 run.py 调用已有函数并设置参数。不得修改其他程序脚本，也不得通过 run.py 间接改写其他脚本。按参考文件填写 param.json、deploy.json 和 layertrans.csv。
- 输入功率采样点和步长由脚本固定，完整 PA 电路 ADE 参数扫描为 -30～30 dBm、等间隔 2 dB、31 点，函数没有提供调整接口。按实际结果行数分析，不要求加密采样，不修改底层或生成脚本来改变扫描。
- Cp/Cs 不由在线程序自动保存，取得数值后立即记入本次设计记录，连同输入、输出网络对应关系和单位保存，供后续仿真使用。

## 完整 PA 电路仿真与优化

### 优化决策原则

- 动态调整优化策略。优化某个参数时，持续评估改善幅度、其他指标的变化和当前瓶颈。多次调整收效甚微或出现明显指标权衡时，重新分析匹配、稳定性、偏置等耦合因素，更新判断并调整优化思路，不得持续机械扫描同一参数。这是 Codex 自身的职责，不以用户提醒为前提。
- 改变放大管尺寸、偏置或中和量后，重新判断原匹配是否有效，不能仅凭“新有源参数＋旧匹配网络”的完整 PA 电路结果排除有源候选。先做少量单参数试验，再按步骤恢复匹配并复查完整 PA 电路，具体见 optimization.md。
- 先区分单频设计与宽带设计。单频设计按指定频率处的性能优化和验收，不额外施加用户未要求的带宽、边缘性能或平坦度约束；稳定性检查仍按原要求执行。宽带设计从初期检查频带下限、中心和上限，按带内最差性能筛选，候选接近要求后补充中间频点并验收平坦度。错峰谐振属于宽带可选优化思路，不是单频设计的默认步骤；具体见 optimization.md 第 8 节。
- 候选由有源参数、偏置、匹配电容和对应网络 S4P 版本共同定义。保留可回退基线，区分网站预计、理想负载、完整 PA 电路中心点和完整 PA 电路全带验证结果，不将未完成验收的候选报告为达标。

### 指标与执行

读取 output 下的原始数据，计算电路指标，报告给用户并判断是否达标。用户要求覆盖频带时，改变传入函数的生成代码频率字段，多次调用仿真函数，检查频带内的性能。

放大指标未达标时，先检查 S11、S22，正常参考为 -10 dB 或更小。匹配较差时先调匹配，匹配尚可时优先调晶体管尺寸。优先处理增益、压缩点输出功率等放大指标，再处理功耗、漏极效率。具体默认优先级及方法见 optimization.md。

效率不足时可调整偏置或输出匹配。降低总工作电压时，遵守用户供电要求，并从网站计算开始重新设计。宽度、偏置和工作频率通过传入仿真函数的生成代码调整。每轮收敛后重新验收完整 PA 电路。
